# Three-Paper Program Scope

## Paper 1 — THIS PROJECT
"When Scientific Output Falls: Separating Scientific Capacity from Resource-Constrained Realization"

- Unit: country × field × year (secondary: institution × field × year).
- Question: does declining internationally visible output uniquely identify declining latent scientific capacity, or is it partly resource-dependent failure to realize an existing stock?
- Competing models: C (capacity loss), R (resource realization), V (publication/visibility constraint). Not a forced binary winner.
- Scope boundary: author-level data used ONLY for the required mobility sensitivity (does high→low resource-intensity reallocation contaminate the low-stratum contrast). No transition-state model. TA analysis limited to feasibility / a compact mechanism check.

## Paper 2 — RESERVED (do not execute)
"Where Scientists Go When Research Becomes Expensive: Resource Constraints, Adaptation, and Reversal"
- Author longitudinal state-transition model: high-capital / low-capital / collaborative / secondary-data / inactive-exit states; P(S_{t+1}=j | S_t=k, resources).
- Full transformative-agreement quasi-experiment (staggered adoption DiD/event study).

## Paper 3 — RESERVED (do not execute)
"Compartment-Based Resource Allocation"
- General theory: A → B decomposed into A1→A2→A3→B; marginal allocation to stock vs transition vs leakage vs bottleneck (∂B/∂I_k) across domains (health, education, development, infrastructure).
- Paper 1 uses the vocabulary (stock vs flow vs transition) only for interpretation; does not establish the general theory.
