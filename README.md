# Scientific Capacity vs. Resource-Constrained Realization (Paper 1)

Working title: **"When Scientific Output Falls: Separating Scientific Capacity from Resource-Constrained Realization"**

Paper 1 of a planned three-paper research program. Macro/meso-level international panel study: does declining internationally visible scientific output uniquely identify declining latent scientific capacity, or is it substantially explained by resource-dependent failure to realize an existing capacity stock?

## Layout

- `data/raw/` — raw data snapshots (never overwritten; acquisition ledger in `data/raw/ACQUISITION_LEDGER.csv`)
- `data/processed/` — cleaned panels and derived variables
- `scripts/` — numbered pipeline scripts (see `scripts/README.md`)
- `docs/` — design documents, QA reports, hostile review, reference audit
- `output/figures`, `output/tables` — publication outputs
- `manuscript/` — journal-neutral manuscript build
- `supplement/` — supplementary material

## Rules

- **No fabrication**: every reported number must be reproducible from code + persisted raw data. No hardcoded estimates in manuscript text — all values flow from `output/` artifacts generated by the pipeline.
- **Raw data persistence**: raw public data are downloaded once, snapshotted under `data/raw/` with source URL, retrieval timestamp (UTC), size, and SHA-256 recorded in the acquisition ledger. Re-downloads create new snapshots, never overwrite.
- Fixed seed: `20260929` wherever stochastic methods are used.
- Deviations from `docs/ANALYSIS_PLAN_FROZEN.md` are logged in `docs/DECISIONS.md` as data-necessity / robustness / exploratory.
